# Gait-Analysis

This is a group project for a Gait Biomechanics course I took. We used Opensim to analyze gait of a real patients with chronic back pain and how it affected their walking in detail. The first part is a literature review of patients with chronic back pain and their gait. Parts 2 and 3 are done using Opensim software. I've put the reports of the project in the repository. They are in Farsi and include photos of opensim environment and results.
